## 1. Authentication & Landing Page

### 1.1 Initial Page Load
**Steps:**
- Navigate to https://tensaigptnew-qa.tensai.run/
- Verify page displays correctly
- Confirm all UI elements are visible

**Expected:**
- Page title shows "Tensai-GPT"
- Welcome heading displays "tensaiGPT"
- Tagline "SMARTER CHATS BRIGHTER IDEAS" is visible
- "SSO Login" button is present and clickable

### 1.2 SSO Login Navigation
**Steps:**
- Click "SSO Login" button on landing page
- Wait for redirect to Microsoft login

**Expected:**
- Redirected to Microsoft Entra ID login
- Sign-in form displays with email/phone/Skype input field
- "Next" button is available
- Sign-in options button is visible
- Footer links (Terms of use, Privacy & cookies) are present

### 1.3 Microsoft Authentication Flow
**Steps:**
- Enter valid Microsoft credentials in email field
- Click "Next" button
- Complete authentication on Microsoft login page
- Wait for redirect back to application

**Expected:**
- User successfully authenticates
- Redirect URI contains `https://tensaigptnew-qa.tensai.run/api/auth/redirect`
- State parameter is preserved in auth flow
- User is logged into tensaiGPT application
