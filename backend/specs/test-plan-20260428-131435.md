# Test Plan for tensaiGPT

**Seed:** tests/seed.spec.ts

---

## 1. Authentication & Login

### 1.1 SSO Login Flow
**Steps:**
1. Navigate to https://tensaigptnew-qa.tensai.run/
2. Verify "Welcome to tensaiGPT" page is displayed
3. Verify "SMARTER CHATS BRIGHTER IDEAS" tagline is visible
4. Click "SSO Login" button
5. User is redirected to Microsoft login page
6. Verify sign-in form displays email/phone/Skype input field
7. Complete Microsoft authentication
8. Verify redirect back to tensaiGPT application

**Expected:**
- User successfully authenticates via SSO
- User is redirected to main application dashboard
- Session is established

### 1.2 Microsoft Sign-In Page Elements
**Steps:**
1. After clicking SSO Login, verify Microsoft sign-in page loads
2. Verify "Sign in" heading is present
3. Verify email/phone/Skype input field with placeholder text
4. Verify "Next" button is clickable
5. Verify "Can't access your account?" link is available
6. Verify "Sign-in options" button is available
7. Verify footer links (Terms of use, Privacy & cookies, Troubleshooting)

**Expected:**
- All sign-in page elements are properly rendered
- All links and buttons are functional
- Footer information is accessible

## 2. Chat Functionality

### 2.1 Chat Interface Availability
**Steps:**
1. Complete SSO authentication
2. Verify user is on main dashboard/chat page
3. Verify chat input area is visible and accessible
4. Verify chat history/conversation area is displayed
5. Verify send message button/functionality is present

**Expected:**
- Chat interface loads successfully
- User can see conversation area and input field
- Chat is ready for message input

### 2.2 Send Chat Message
**Steps:**
1. After successful authentication, locate chat input field
2. Type a test message in the chat input
3. Click send button or press Enter
4. Verify message appears in conversation thread
5. Wait for response/AI processing

**Expected:**
- Message is successfully sent
- Message appears in chat history
- Application processes the message

### 2.3 Multi-turn Conversation
**Steps:**
1. Send initial chat message
2. Wait for response
3. Send follow-up message
4. Verify conversation maintains context
5. Send additional messages in sequence

**Expected:**
- Conversation history is maintained
- Messages appear in correct chronological order
- Context is preserved across multiple turns

### 2.4 Chat Message Formatting
**Steps:**
1. Send message with special characters
2. Send message with line breaks
3. Send message with emojis
4. Send long message (>500 characters)
5. Verify all messages display correctly

**Expected:**
- Messages render properly with all content intact
- Formatting is preserved
- No truncation or encoding issues

## 3. Agent Selection

### 3.1 Agent/Assistant Selection
**Steps:**
1. Verify agent selection interface is available
2. Identify available agents/assistants in the application
3. Click on first agent option
4. Verify agent is selected (visual indicator)
5. Compose message with selected agent
6. Send message and verify correct agent processes request

**Expected:**
- Agent selection dropdown/menu is visible
- Multiple agents are available for selection
- Selected agent is highlighted/confirmed
- Messages are routed to correct agent

### 3.2 Agent Switching
**Steps:**
1. Start conversation with Agent A
2. Switch to Agent B from selection menu
3. Send new message
4. Verify Agent B is now active
5. Switch back to Agent A
6. Send another message
7. Verify Agent A processes the message

**Expected:**
- Agents can be switched during conversation
- Each agent handles messages appropriately
- No loss of previous conversation data

### 3.3 Agent Information/Description
**Steps:**
1. Hover over or click on agent name
2. Verify agent description/purpose is displayed
3. Verify agent capabilities are listed (if available)
4. Verify switching between agents updates information

**Expected:**
- Agent information is clearly presented
- Users understand each agent's purpose
- Information updates when agent selection changes

## 4. File Upload Functionality

### 4.1 File Upload Interface
**Steps:**
1. Locate file upload option (button/drag-drop area)
2. Verify upload area is visible and labeled
3. Verify file type restrictions are indicated (if any)
4. Verify file size limits are communicated

**Expected:**
- File upload interface is accessible
- Upload instructions are clear
- File restrictions are displayed

### 4.2 Single File Upload
**Steps:**
1. Click file upload button
2. Select a supported file type (PDF, TXT, DOC, etc.)
3. Verify file is selected in the upload interface
4. Confirm file upload
5. Verify file appears in chat/upload area
6. Verify upload progress indicator (if applicable)
7. Wait for upload completion

**Expected:**
- File is successfully selected
- Upload progress is indicated
- File appears in conversation with confirmation
- No errors during upload

### 4.3 Multiple File Upload
**Steps:**
1. Upload first file and verify completion
2. Upload second file
3. Verify both files are visible in conversation
4. Send message referencing uploaded files
5. Verify AI references correct files

**Expected:**
- Multiple files can be uploaded sequentially
- All files are retained in conversation
- AI can reference multiple files in responses

### 4.4 File Upload Error Handling
**Steps:**
1. Attempt to upload unsupported file type (if restrictions exist)
2. Attempt to upload file exceeding size limit
3. Attempt to upload corrupted/invalid file
4. Verify appropriate error messages are displayed
5. Verify user can retry upload

**Expected:**
- Appropriate error messages for invalid uploads
- Users are guided on valid file requirements
- File upload can be retried after error

### 4.5 File Interaction in Chat
**Steps:**
1. Upload a file successfully
2. Send message asking to analyze/review the file
3. Verify agent processes file content
4. Verify file reference in AI response
5. Ask follow-up questions about file content
6. Verify context is maintained

**Expected:**
- Agent acknowledges uploaded file
- Agent can analyze and discuss file content
- File context is maintained across conversation turns
- Accurate information from file is extracted

### 4.6 File Download/Preview (if applicable)
**Steps:**
1. Upload a file
2. Look for preview or download option
3. Verify file can be previewed in-app (if supported)
4. Verify file can be downloaded back to local system
5. Verify downloaded file integrity

**Expected:**
- Files can be viewed or downloaded as needed
- File content is not corrupted
- File metadata is preserved

## 5. General UI/UX

### 5.1 Responsive Design
**Steps:**
1. Test on desktop browser (1920x1080)
2. Test on tablet browser (768x1024)
3. Test on mobile browser (375x667)
4. Verify chat interface remains functional
5. Verify file upload works on all devices
6. Verify agent selection works on all devices

**Expected:**
- UI adapts to different screen sizes
- All functionality remains accessible
- No layout breaking or overflow issues

### 5.2 Loading States
**Steps:**
1. Trigger message send and observe loading indicator
2. Upload file and observe upload progress
3. Switch agents and verify loading state
4. Verify loading indicators clear appropriately

**Expected:**
- Loading states are visible to user
- Indicators clear when actions complete
- No indefinite loading states

### 5.3 Error Handling & Recovery
**Steps:**
1. Attempt action with no internet connection (simulate)
2. Attempt message send and simulate failure
3. Verify error message is displayed
4. Verify retry functionality is available
5. Restore connection and verify recovery

**Expected:**
- Errors are communicated clearly
- Recovery options are provided
