# Test Plan for Tensai-GPT

**Seed:** tests/seed.spec.ts

---

## 1. Authentication & Access

### 1.1 SSO Login Flow
**Steps:**
1. Navigate to https://tensaigptnew-qa.tensai.run/
2. Verify "Welcome to tensaiGPT" heading is displayed
3. Verify tagline "SMARTER CHATS BRIGHTER IDEAS" is visible
4. Click "SSO Login" button
5. Complete SSO authentication process
6. Verify user is redirected to main application

**Expected:**
- SSO Login button is clickable and responsive
- User successfully authenticates via SSO
- Application loads post-authentication page/dashboard
- User session is established

## 2. Chat Functionality

### 2.1 Initialize New Chat
**Steps:**
1. Log in via SSO
2. Locate chat interface/input area
3. Verify chat window is ready for input
4. Click on chat input field

**Expected:**
- Chat input field is accessible and focused
- Cursor appears in input field
- Chat interface is fully loaded

### 2.2 Send Basic Message
**Steps:**
1. Click chat input field
2. Type a test message (e.g., "Hello")
3. Press Enter or click Send button
4. Wait for response

**Expected:**
- Message appears in chat history
- User message is attributed correctly
- AI response is generated and displayed
- Chat maintains message order and formatting

### 2.3 Chat History Persistence
**Steps:**
1. Send multiple messages in conversation
2. Refresh page or navigate away
3. Return to chat window
4. Verify previous messages are visible

**Expected:**
- All previous messages are preserved
- Chat history loads correctly
- Message order is maintained
- Timestamps are accurate (if applicable)

### 2.4 Clear Chat/New Conversation
**Steps:**
1. Complete a conversation
2. Look for "New Chat" or "Clear" button
3. Click to start new conversation
4. Verify previous messages are cleared

**Expected:**
- New conversation starts with empty chat
- Previous conversation can be accessed/archived
- No messages from previous chat are visible

## 4. File Upload Functionality

### 4.1 Access Upload Feature
**Steps:**
1. In active chat, locate file upload button/icon
2. Click upload button
3. Verify file picker dialog opens

**Expected:**
- File upload button is visible and accessible
- File picker dialog appears with file browser
- Dialog is functional and responsive

### 4.2 Upload Single File
**Steps:**
1. Click file upload button
2. Select a test file (PDF, TXT, CSV, etc.)
3. Confirm selection
4. Wait for upload to complete
5. Verify file appears in chat interface

**Expected:**
- File is successfully uploaded
- File name/preview is displayed in chat
- Upload progress is indicated (if applicable)
- No error messages appear
- File remains accessible in conversation

### 4.3 Upload Multiple Files
**Steps:**
1. Click file upload button
2. Select multiple files (if supported)
3. Confirm selections
4. Wait for uploads to complete
5. Verify all files appear in chat

**Expected:**
- Multiple files can be selected simultaneously (if supported)
- All files are uploaded and displayed
- Each file is individually identifiable
- Chat context includes all uploaded files

### 4.4 Supported File Types
**Steps:**
1. Attempt to upload various file types:
   - Text files (.txt, .md)
   - Documents (.pdf, .docx)
   - Data files (.csv, .json)
   - Images (.png, .jpg)
   - Code files (.py, .js)
2. Note which types are accepted/rejected

**Expected:**
- Supported file types are accepted
- Unsupported file types show clear error message
- File size limitations are enforced with messages
- Error messages guide user to supported formats

### 4.5 Reference Uploaded Files in Chat
**Steps:**
1. Upload a file
2. Send message referencing the uploaded file
3. Request analysis/processing of file content
4. Verify AI response includes file data

**Expected:**
- Chat AI can access and reference uploaded files
- File content is included in context
- Responses are based on file information
- File reference is clear in conversation

### 4.6 Delete/Remove Uploaded Files
**Steps:**
1. Upload a file
2. Locate delete/remove option for file
3. Click to remove file
4. Verify file is no longer in chat

**Expected:**
- Delete option is available
- File is removed from chat interface
- Subsequent messages don't reference deleted file
- Chat history updates appropriately

## 5. Integration & Edge Cases

### 5.1 Large File Upload
**Steps:**
1. Attempt to upload a large file (>50MB if supported)
2. Monitor upload progress
3. Wait for completion
4. Verify file is processed correctly

**Expected:**
- Large files are handled gracefully
- Upload doesn't timeout or fail
- User is informed of progress
- File is accessible post-upload

### 5.2 Concurrent Operations
**Steps:**
1. Upload file while sending chat message
2. Switch agents during upload
3. Start new chat during file processing
4. Observe system behavior

**Expected:**
- Operations don't interfere with each other
- System handles concurrent requests gracefully
- No data loss occurs
- UI remains responsive

### 5.3 Session Timeout
**Steps:**
1. Log in and start active session
2. Wait for extended idle period (or simulate timeout)
3. Attempt to send message
4. Observe authentication handling

**Expected:**
- User is prompted to re-authenticate if session expires
- Previous chat is preserved or recoverable
- No data loss occurs
- Clear messaging about session status

### 6.1 Responsive Design
**Steps:**
1. Test on desktop (1920x1080)

4. Verify all features are accessible at each breakpoint

**Expected:**
- Layout adapts to screen size
- All buttons and inputs are usable

### 6.2 Performance
**Steps:**
1. Monitor page load time
2. Monitor chat response time
3. Monitor file upload speed

**Expected:**
- Page loads in <3 seconds
- Chat responses appear within 5 seconds
- File uploads show progress indication
