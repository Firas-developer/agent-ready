# Test Plan for Tensai-GPT

**Seed:** tests/seed.spec.ts

## 1. Authentication & Login

### 1.1 SSO Login Flow
**Steps:**
1. Navigate to https://tensaigptnew-qa.tensai.run/
2. Verify "Welcome to tensaiGPT" heading is displayed
3. Click "SSO Login" button
4. Verify redirect to Microsoft login page (login.microsoftonline.com)
5. Verify "Sign in" heading and email input field are displayed
6. Enter valid email credentials
7. Click "Next" button
8. Complete Microsoft authentication flow
9. Verify redirect back to main Tensai-GPT application

**Expected:**
- User successfully authenticates via SSO
- Dashboard/chat interface loads after successful login
- User session is established

### 1.2 Sign-in Options Availability
**Steps:**
1. On Microsoft login page, click "Sign-in options" button
2. Verify alternative sign-in methods are displayed
3. Select available sign-in method
4. Proceed with authentication

**Expected:**
- Multiple sign-in options are accessible
- User can choose alternative authentication method

### 1.3 Account Recovery
**Steps:**
1. On Microsoft login page, click "Can't access your account?" link
2. Verify account recovery page loads
3. Follow recovery workflow

**Expected:**
- Account recovery option is accessible
- User can initiate account recovery process

## 3. Agent Selection

### 3.1 Agent List Display
**Steps:**
1. User is authenticated and on main interface
2. Locate agent selection area/dropdown
3. Verify list of available agents is displayed
4. Check each agent name and description

**Expected:**
- All available agents are listed
- Agent names are clearly visible
- Agent descriptions/capabilities are shown

### 3.2 Select Different Agents
**Steps:**
1. Select first agent from list
2. Verify agent is selected (visual indicator)
3. Initiate chat with selected agent
4. Send test message
5. Switch to different agent
6. Send another test message
7. Repeat for all available agents

**Expected:**
- Agent selection changes successfully
- Selected agent responds appropriately
- Context switches between agents work correctly
- Each agent behaves according to its role

### 3.3 Agent Context Persistence
**Steps:**
1. Select Agent A
2. Send message and receive response
3. Switch to Agent B
4. Verify previous Agent A context is not mixed with Agent B responses
5. Send message to Agent B
6. Switch back to Agent A
7. Verify conversation history with Agent A is preserved

**Expected:**
- Each agent maintains separate conversation context
- No context bleeding between agents
- Previous conversations are retrievable when switching back

## 4. File Upload Functionality

### 4.1 File Upload Button Availability
**Steps:**
1. User is authenticated and on chat interface
2. Locate file upload button/icon
3. Verify upload button is clickable
4. Click to open file picker

**Expected:**
- File upload button is visible and accessible
- File picker dialog opens

### 4.2 Single File Upload
**Steps:**
1. Click file upload button
2. Select a single file (e.g., .txt, .pdf, .docx)
3. Verify file is selected in picker
4. Confirm upload
5. Wait for upload completion
6. Verify file appears in chat interface

**Expected:**
- File is successfully uploaded
- Upload progress is indicated
- File appears in chat with name/icon
- File is associated with current agent/conversation

### 4.3 Multiple File Upload
**Steps:**
1. Click file upload button
2. Select multiple files
3. Verify all files are selected
4. Confirm upload
5. Wait for all uploads to complete
6. Verify all files appear in chat interface

**Expected:**
- Multiple files can be selected
- All files upload successfully
- Each file is displayed in chat
- Upload handles multiple files without errors

### 4.4 File Upload Error Handling
**Steps:**
1. Attempt to upload unsupported file type
2. Attempt to upload file exceeding size limit (if applicable)
3. Verify appropriate error messages are displayed
4. Try valid file after error
5. Verify upload succeeds after correction

**Expected:**
- Unsupported file types show error message
- File size limits are enforced with clear messaging
- User can recover and retry
- Error doesn't break chat functionality

### 4.5 File Interaction in Chat
**Steps:**
1. Upload a file successfully
2. Send chat message referencing the uploaded file
3. Request agent to analyze/summarize file content
4. Verify agent can access and process file
5. Verify response includes file content analysis

**Expected:**
- Agent can access uploaded files
- Agent can process and analyze file content
- Agent references file correctly in responses
- File context is maintained in conversation

### 4.6 File Management
**Steps:**
1. Upload multiple files in same conversation
2. Locate file list/panel
3. Verify all uploaded files are listed
4. Attempt to delete/remove a file
5. Verify file is removed
6. Continue chat without removed file
7. Send message to verify agent no longer references deleted file

**Expected:**
- All uploaded files are viewable
- Files can be removed from conversation
- Agent respects file removal
- Chat continues normally after file removal

**Steps:**
1. Send sensitive message (e.g., containing numbers that look like credentials)

3. Verify data is encrypted in transit

**Expected:**
- Messages are encrypted in transit (HTTPS)

### 8.2 Session Security
**Steps:**
1. Authenticate and note session cookie
2. Attempt to use expired session
3. Attempt to use modified session token
4. Verify session validation works

**Expected:**
- Sessions are validated on each request
- Expired sessions are rejected
