# Test Plan for Tensai-GPT

**Seed:** tests/seed.spec.ts

## 1. Authentication & Landing Page

### 1.1 Initial Page Load and Layout
**Steps:**
1. Navigate to https://tensaigptnew-qa.tensai.run/
2. Observe page title and header elements
3. Verify all UI components render correctly

**Expected:**
- Page title displays "Tensai-GPT"
- Welcome message displays "Welcome to tensaiGPT"
- Tagline "SMARTER CHATS BRIGHTER IDEAS" is visible
- SSO Login button is present and interactive

### 1.2 SSO Login Flow
**Steps:**
1. Click "SSO Login" button
2. Verify redirect to authentication provider
3. Complete SSO authentication
4. Verify redirect back to application

**Expected:**
- User is authenticated
- Redirected to main chat interface
- User session is established
- User profile/identity is visible

## 4. File Upload Functionality

### 4.1 File Upload UI Discovery
**Steps:**
1. Locate file upload mechanism in chat interface
2. Identify upload button/area
3. Check for supported file types information
4. Verify upload size limits (if displayed)

**Expected:**
- File upload button/area is clearly visible
- File type restrictions are documented
- Size limitations are shown
- UI is intuitive and accessible

### 4.2 Single File Upload - Text Document
**Steps:**
1. Click file upload button
2. Select a .txt or .pdf file (< 5MB)
3. Confirm file selection
4. Wait for upload completion
5. Verify file appears in chat context

**Expected:**
- File dialog opens
- Selected file is displayed in upload area
- Upload progress indicator shows
- File confirmation message appears
- File is available for chat reference

### 4.3 Single File Upload - Code File
**Steps:**
1. Click file upload
2. Select a code file (.py, .js, .ts, .java, etc.)
3. Complete upload
4. Send message asking analysis of file
5. Verify AI can reference file contents

**Expected:**
- Code file uploads successfully
- AI can analyze and discuss code
- Syntax highlighting/formatting (if applicable)
- References to specific line numbers work

### 4.4 Multiple File Upload
**Steps:**
1. Upload first file
2. Upload second file
3. Upload third file
4. Send query referencing multiple files
5. Verify AI cross-references files

**Expected:**
- Multiple files upload without error
- All files are visible in context
- AI can correlate information across files
- No file conflicts or overwriting occurs

### 4.5 File Upload - Unsupported Format
**Steps:**
1. Attempt to upload unsupported file type (.exe, .zip)
2. Observe system response
3. Check error message clarity

**Expected:**
- Upload is rejected with clear message
- Error explains why file type not supported
- User can try again without session disruption
- Alternative formats are suggested

### 4.6 File Upload - Oversized File
**Steps:**
1. Attempt to upload file exceeding size limit
2. Observe system response
3. Check for suggestions to reduce size

**Expected:**
- Upload rejected before processing
- Clear error message about file size
- Size limit is clearly communicated
- No partial upload or corruption occurs

### 4.7 File Upload - Special Characters
**Steps:**
1. Upload file with special characters in filename
2. Verify file handles correctly in system
3. Reference file in chat by name

**Expected:**
- Filename is preserved or sanitized
- File is accessible in chat context
- No filename-related errors occur

### 4.8 File Reference in Chat
**Steps:**
1. Upload a file
2. Send message: "Summarize this file"
3. Send message: "What is the main topic?"
4. Send message: "Extract key points"
5. Verify AI maintains file context

**Expected:**
- AI correctly references uploaded file
- File context persists across multiple messages
- Accurate information extracted from file
- Context is not confused with other files

### 4.9 Clear/Remove Files from Context
**Steps:**
1. Upload file(s)
2. Look for file management options
3. If available, remove file from context
4. Send new message
5. Verify file is no longer referenced

**Expected:**
- File removal option is available (if feature exists)
- Chat context updates appropriately
- AI no longer references removed file
- New context is established

## 5. Integration & Edge Cases

### 5.1 Chat + File + Agent Integration
**Steps:**
1. Select specific agent
2. Upload relevant file
3. Ask agent to analyze file
4. Switch agent while file is loaded
5. Query new agent about file

**Expected:**
- Agent, file, and chat work together seamlessly
- File context transfers between agents
- Each agent processes file according to specialization
- No data loss during agent switch

### 5.2 Session Persistence
**Steps:**
1. Have active conversation with files uploaded
2. Refresh page (F5)
3. Verify session state
4. Check if conversation/files are restored

**Expected:**
- Session is maintained or gracefully restored
- Conversation history is preserved (if feature)
- User remains authenticated
- Clear messaging about session state

### 5.3 Error Recovery
**Steps:**
1. Send very long message (5000+ characters)
2. Upload maximum size allowed
3. Interrupt upload mid-way
4. Attempt chat during network latency
5. Observe error handling

**Expected:**
- Long messages are handled correctly
- Large files process without timeout
- Interrupted uploads can be retried
- Network errors show helpful messages
- No permanent session corruption
