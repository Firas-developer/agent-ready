# Test Plan for tensaiGPT

**Seed:** tests/seed.spec.ts

---

## 1. Authentication & Login

### 1.1 SSO Login Flow
**Steps:**
1. Navigate to https://tensaigptnew-qa.tensai.run/
2. Verify "Welcome to tensaiGPT" heading is displayed
3. Verify "SMARTER CHATS BRIGHTER IDEAS" tagline is visible
4. Click "SSO Login" button
5. User is redirected to Microsoft login page
6. Verify Sign in page loads with email/phone input field
7. Enter valid credentials
8. Click "Next" button
9. Complete MFA if required
10. User is redirected back to tensaiGPT application

**Expected:**
- SSO Login button is clickable and functional
- Microsoft authentication flow completes successfully
- User is authenticated and session is established
- Dashboard/Chat interface loads after successful authentication

### 1.2 Login Error Handling
**Steps:**
1. Click "SSO Login" button
2. Enter invalid credentials on Microsoft login page
3. Observe error handling behavior
4. Verify "Can't access your account?" link is functional
5. Attempt account recovery flow

**Expected:**
- Clear error message is displayed for invalid credentials
- Recovery link works properly
- User can retry login without issues

## 3. Agent Selection

### 3.1 View Available Agents
**Steps:**
1. After authentication, locate agent selection area
2. Observe list of available agents
3. Verify agent names are clearly displayed
4. Check if agent descriptions/icons are visible
5. Verify number of available agents

**Expected:**

- Each agent is clearly identifiable
- Agent descriptions or capabilities are displayed

### 3.2 Select Different Agent
**Steps:**
1. Start with default or first agent selected
2. Click on a different agent from the list
3. Verify agent is now selected (highlighted)
4. Send a message to the new agent
5. Switch to another agent and repeat

**Expected:**
- Agent selection is responsive
- Selected agent is visually highlighted
- Chat messages are sent to correct agent
- Agent context is properly maintained
- Agent-specific responses are generated

### 3.3 Agent-Specific Capabilities
**Steps:**
1. Select Agent A and send task request
2. Observe agent-specific responses/features
3. Select Agent B and send same/similar request
4. Compare responses and capabilities
5. Verify specialized agent handling

**Expected:**
- Each agent provides appropriate responses
- Specialized agents handle relevant tasks better

### 3.4 Agent Switching During Conversation
**Steps:**
1. Start conversation with Agent A

- Previous messages remain in history

## 4. File Upload Functionality

### 4.1 File Upload Interface
**Steps:**
1. Locate file upload option in chat interface
2. Verify upload button/area is visible and accessible
3. Click on upload button
4. File selection dialog appears
5. Verify file browser opens correctly

**Expected:**
- File upload option is clearly visible
- Upload button is clickable and responsive
- File browser dialog opens without errors
- File selection interface is user-friendly

### 4.2 Single File Upload
**Steps:**
1. Click file upload button
2. Select a single supported file (e.g., .pdf, .txt, .docx)
3. Verify file is selected and filename displays
4. Click Upload or Confirm
5. Observe upload progress indicator
6. Wait for upload completion

**Expected:**
- File is accepted by the system
- Upload progress is visible
- File upload completes successfully
- Confirmation message is displayed
- File appears in chat context

### 4.3 Multiple File Upload
**Steps:**
1. Click file upload button
2. Select multiple files at once (if supported)
3. Or upload files sequentially
4. Verify all files are queued/uploaded
5. Observe upload status for each file
6. Verify all files are processed

**Expected:**
- Multiple files can be uploaded
- Upload status is tracked for each file
- All files are successfully processed
- Files are associated with chat session

### 4.4 Supported File Types
**Steps:**
1. Attempt to upload .pdf file
2. Attempt to upload .txt file
3. Attempt to upload .docx or .doc file
4. Attempt to upload .csv or .xlsx file
5. Attempt to upload unsupported file type (.exe, .zip)

**Expected:**
- Supported files upload successfully
- Unsupported files show error message
- Error message clearly indicates reason
- File type restrictions are enforced

### 4.5 File Size Limits
**Steps:**
1. Upload a small file (< 1MB)
2. Verify upload succeeds
3. Attempt to upload very large file (> size limit)
4. Observe error handling
5. Verify file size restrictions are communicated

**Expected:**
- Small files upload without issues
- Large files are rejected with clear error message
- File size limit is documented/communicated
- Error handling is graceful

### 4.6 File Processing & Chat Integration
**Steps:**
1. Upload a document file
2. Verify file appears in chat interface
3. Send a message referencing the uploaded file
4. Agent analyzes/references the file in response
5. Ask follow-up questions about file content

**Expected:**
- File is visible in chat context
- Agent can access file content
- References to file are accurate
- Agent provides relevant responses based on file

### 4.7 Multiple File Context in Chat
**Steps:**
1. Upload File A and send a message about it
2. Upload File B and send a message about it
3. Send a message asking to compare/analyze both files
4. Verify agent references both files correctly
5. Check cross-file analysis/synthesis

**Expected:**
- Both files remain accessible to agent
- Agent can compare/synthesize across files
- Context includes all uploaded files
- Responses reference correct file data

### 4.8 File Upload Error Handling
**Steps:**
1. Attempt upload with poor network connection
2. Try uploading corrupted file
3. Attempt to upload file with invalid name characters
4. Test upload cancellation mid-process
5. Retry after error

**Expected:**
- Network errors provide clear messaging
- Corrupted files are detected and rejected
- Invalid filenames are flagged
- Upload can be cancelled gracefully
- User can retry without session issues

### 4.9 File Management
**Steps:**
1. Upload multiple files
2. Locate file management/history area
3. Attempt to view uploaded files list
4. Try to remove/delete a file (if option exists)
5. Verify file is no longer available to agent

**Expected:**
- File history is visible or accessible

### 4.10 File Upload with Chat Message
**Steps:**
1. Attach file to message
2. Add accompanying text message

4. Verify file and message are processed together

**Expected:**

**Steps:**
1. Authenticate successfully

3. Attempt to send message
4. Verify timeout handling
5. Check re-authentication flow

**Expected:**
- Session timeout is handled gracefully
- User is notified of timeout
- Re-authentication option is provided
- No data loss upon timeout

### 6.2 Network Connectivity Issues
**Steps:**
1. Go offline during active chat
2. Attempt to send message
3. Observe error handling
4. Restore connectivity
5. Verify recovery without data loss

**Expected:**
- Network errors are clearly communicated
- Failed messages can be retried
- Connection recovery is smooth
- No duplicate messages on reconnect
