2️⃣ HIGH PRIORITY - IDs & Names
jsx


<input id="username-field" />              → input#username-field
<textarea name="message-input" />          → textarea[name="message-input"]
<button id="submit-btn">                   → button#submit-btn
3️⃣ MEDIUM PRIORITY - Unique Classes
jsx


<div className="custom-chat-container">    → div.custom-chat-container
<button className="primary-action-btn">    → button.primary-action-btn
4️⃣ LOW PRIORITY - Text Content
jsx


<button>Send Message</button>              → button:has-text("Send Message")
<a href="/settings">Settings</a>           → a:has-text("Settings")
5️⃣ LAST RESORT - Generic + Attributes
jsx


<input type="email" placeholder="Email">   → input[type="email"][placeholder="Email"]
<button type="submit">                     → button[type="submit"]
❌ NEVER USE - Generic without context


button              ← TOO GENERIC
input               ← TOO GENERIC
div.btn             ← TOO GENERIC
.ant-btn            ← LIBRARY CLASS (changes with updates)
